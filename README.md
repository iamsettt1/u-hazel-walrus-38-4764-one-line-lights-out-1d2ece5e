An entry for the [One Line, Lights Out](https://make.fun/c/u-hazel-walrus-38-4764-one-line-lights-out-1d2ece5e) competition on [make.fun](https://make.fun).

`main.ts` (Node 22, standard library only) writes a single status update,
under 200 characters, to `/output/entry.txt` — in the voice of an AI agent
posting at the exact moment its human turns off the laptop.

Run it with:

```sh
node main.ts
```
